# Study Compass v5

기존 Study Compass 타이머에 **기록 보관함(전체 누적·일별·월별·공부 달력·연속 공부일)**, 성적 관리, 문항별 오답 데이터베이스, 취약 유형 집계, 최근 7일 공부 리포트를 추가한 버전입니다.

## 업데이트 방법
1. ZIP 압축을 풉니다.
2. `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`를 기존 GitHub 저장소의 같은 위치에 업로드하고 덮어씁니다.
3. Commit changes를 누릅니다.
4. GitHub Pages 배포가 완료되면 사이트를 새로고침합니다.

## 데이터 보존
기존 버전과 동일한 브라우저 저장 키(`studyCompassV2`)를 사용하므로 기존 공부 기록, 목표, 회고, 타이머 상태를 이어서 사용합니다. 새 성적/시험/오답 데이터도 같은 브라우저에 저장됩니다. 브라우저 데이터 삭제 전 백업 파일을 내보내세요. 다른 기기와 자동 동기화되지는 않습니다.

## v5 추가 기능
- 기록 보관함 탭: 전체 누적 시간, 연속 공부일, 공부 달력, 일별/월별 기록
- 백업 파일 불러오기(기존 기록과 병합), 브라우저 저장소 보호 요청
- `sw.js` 캐시 이름을 변경해 업데이트가 바로 반영됩니다.
