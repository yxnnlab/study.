# Study Compass v6.3

기존 Study Compass 타이머에 **기록 보관함(전체 누적·일별·월별·공부 달력·연속 공부일)**, 성적 관리, 문항별 오답 데이터베이스, 취약 유형 집계, 최근 7일 공부 리포트를 추가한 버전입니다.

## 업데이트 방법
1. ZIP 압축을 풉니다.
2. `index.html`, `sw.js`, `sync-config.js`, `README.md`, `SYNC_SETUP.md`를 기존 GitHub 저장소의 같은 위치에 업로드하고 덮어씁니다. (`manifest.webmanifest`는 변경 없음. 동기화 설정 후에는 `sync-config.js`를 다시 덮어쓰지 마세요.)
3. Commit changes를 누릅니다.
4. GitHub Pages 배포가 완료되면 사이트를 **두 번** 새로고침하거나 앱을 완전히 닫았다가 다시 엽니다. (이전 버전의 캐시가 한 번 먼저 보일 수 있어요. v6부터는 업데이트가 바로 반영됩니다.) **"사이트 데이터 삭제"는 기록이 지워지니 하지 마세요.**

## 데이터 보존
기존 버전과 동일한 브라우저 저장 키(`studyCompassV2`)를 사용하므로 기존 공부 기록, 목표, 회고, 타이머 상태를 이어서 사용합니다. 새 성적/시험/오답 데이터도 같은 브라우저에 저장됩니다. 브라우저 데이터 삭제 전 백업 파일을 내보내세요. 다른 기기와 자동 동기화되지는 않습니다.

## v5 추가 기능
- 기록 보관함 탭: 전체 누적 시간, 연속 공부일, 공부 달력, 일별/월별 기록
- 백업 파일 불러오기(기존 기록과 병합), 브라우저 저장소 보호 요청
- `sw.js` 캐시 이름을 변경해 업데이트가 바로 반영됩니다.

## v6 변경
- 업데이트가 반영되지 않던 서비스워커 캐시 문제 수정(네트워크 우선)
- 자정을 넘긴 타이머 기록을 날짜별로 나눠 저장, 앱을 켜 둔 채 자정이 지나면 입력 날짜 자동 갱신
- Firebase 로그인 기반 기기 간 동기화 (`SYNC_SETUP.md`)

## v6.2~6.3 변경
- 기본 과목 제거: 사용자가 직접 과목 추가/삭제 (기존 기록의 과목은 자동 유지)
- 계획 탭 추가: 월간 계획, 주간 계획(월요일 시작), 사용자 시간표
- 오늘 화면에 오늘 시간표·오늘의 계획 표시
- 계획·목표·시간표·과목도 기기 간 동기화
